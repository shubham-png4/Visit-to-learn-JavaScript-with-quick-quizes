# JS Quest - Learn JavaScript by Playing 🎮

An interactive quiz game designed to help beginners and intermediate developers learn and reinforce JavaScript concepts in a fun way.

## Features

- 8 carefully chosen JavaScript questions
- Real-time scoring system
- Detailed explanations after each answer
- Modern responsive design
- Progress tracking
- Restart functionality

## How to Run

1. Clone or download the repository
2. Open `index.html` in your browser
3. Start learning JavaScript while having fun!

## Topics Covered

- Variable declaration (`let`, `const`)
- Type coercion
- Functions (traditional + arrow)
- Array methods (`push`, `join`)
- Strict equality (`===`)
- Looping through arrays
- And more!
